## Procedural Nodes for Textures and Dynamic Material Properties

**Author:** Elpida-Kalliopi D. Anthopoulou  
**Institution:** Democritus University of Thrace (DUTH)  
**Software:** Blender 4.2  

## Overview
This repository contains the source files and documentation for my undergraduate thesis on procedural texturing in **Blender**. The project demonstrates how to construct complex materials using PBR shader nodes without relying on external image textures.

## Included Materials
- **Aqua Marble**
- **Black Veined Marble**
- **Layered Rock**
- **Asteroid with Craters**
- **Oxidized Bronze Metal**
- **Scratched Metal**

## File Contents
- `Thesis_Document.pdf` - Complete thesis text.
- `Materials.blend` - Blender project containing all Node Groups and shaders.
- `/renders` - High-resolution render samples of each material.
